Privacy

Menu settimanale accede solo ai file che crea nel Google Drive dell'utente, per allinearli tra i suoi dispositivi. Nessun dato viene raccolto, inviato a server o condiviso con terzi.

L'uso dei dati ricevuti dalle API di Google rispetta le Google API Services User Data Policy, inclusi i requisiti di Limited Use.

L'accesso può essere revocato in qualsiasi momento dalle impostazioni dell'account Google.
